# 🍕 Pizzeria IL Migliore – Sito Web Dinamico

Questo progetto è un sito web completo sviluppato per una pizzeria reale.  
Include un menu dinamico, gestione allergeni conforme alla normativa EU 1169/2001, un sistema avanzato di personalizzazione delle pizze e un’interfaccia moderna con effetti grafici.

---

## ✨ Funzionalità principali

- Menu completo: pizze, focacce, kebab, calzoni, teglie, bibite  
- Sistema allergeni EU 1169/2001 con overlay informativi  
- Personalizzazione ingredienti con calcolo dinamico del prezzo  
- Effetti grafici: starfield, shooting stars, neon gradient  
- Design responsive per mobile e tablet  
- Audio ambientale stagionale  
- Navigazione intuitiva con card‑menu  

---

## 🛠 Tecnologie utilizzate

- **HTML5**  
- **CSS3** (animazioni, gradienti, responsive)  
- **JavaScript Vanilla**

## 🧠 Logiche implementate
